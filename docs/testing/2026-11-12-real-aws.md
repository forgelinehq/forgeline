# Real checks on AWS and the Pi, 2026-11-12

What was run against real services on the maintainer's Raspberry Pi Forgeline (OpenTofu 1.13.9, AWS provider 6.7x,
region ap-south-1), what it showed, and what was cleaned up. Account numbers are masked in every picture and log.
Proposals were made by the `claude-agent` test user and approved by a second principal (the server token), with the
maintainer's go-ahead; the first removal was approved by the maintainer.

## 1. Removing what a blueprint built (note 041)

A free test blueprint: a queue, a table, a versioned bucket and a log group.

| Step | Preview | Applied | AWS afterwards |
| --- | --- | --- | --- |
| Build | 8 to add | 8 added | queue, table, bucket, log group exist |
| Keep the data | 2 to remove | 2 removed | table (deletion protection on) and bucket stay; queue and log group gone |
| Remove everything, step 1 | 2 to change | 2 changed | table protection off, bucket may be deleted with its files |
| Remove everything, step 2 | 6 to remove | 6 removed | no `fl-` tables, buckets or queues |

The same was done earlier for a second blueprint with a file put in its bucket first (8 added; 2 changed and 2 removed;
6 removed), and for the 2026-11-08 test queue (2 removed, approved by the maintainer).

## 3. A Marketplace team with the real assistant

The incident triage team was installed, its workflow run once with the real assistant, and the package uninstalled (its
agents and workflow are off; their history is kept). Both agents of the first stage ran together and each named the
lookups behind its findings (the run analyst `list_runs`; the platform checker `morning_check`, `aws_resources` and
`k8s_clusters`). The run analyst found no failed runs and said so instead of guessing. The lead wrote one report from
both. What they found in the account is not repeated here: this repository is public.

![Team]({{ '/console/129-check-08-team.png' | relative_url }})

## Found and fixed

- Cloud changes and AI proposals were listed in random order (their ids are random), and only a random 100 were
  shown once there were more. They are now newest first.
- Watch › Services waited for the full account summary before drawing; it now draws at once.
- A step-1 removal title said "and remove the rest (0)".
- A blueprint could not be deleted after everything it built was removed (fixed the same day).

## Not checked, and why

- **Apps, AgentCore agents and images built by GitHub Actions on real AWS.** They need IAM roles named `fl-*` and GitHub's
  OIDC provider in the account. Attaching that permission and creating the provider are IAM changes an administrator
  makes; they are written out in the [Connect AWS guide]({{ '/guides/connect-aws/' | relative_url }}).
