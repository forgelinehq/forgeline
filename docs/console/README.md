# Screenshots

The guides use a few screenshots each, cropped to the part of a page the text talks about. They are made from a
running console with `python3 scripts/docs/crop.py <source.png> <name.png> <y0> <y1>`, which drops the sidebar and top
bar. A picture older than the page it shows is a bug in the guide: retake it when the page changes.

There is no gallery. Earlier full-window pictures that no page uses any more were removed; they stay in the git history.
